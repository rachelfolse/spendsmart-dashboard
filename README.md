# SpendSmart Dashboard

The SpendSmart Dashboard is a web application designed to help users track, manage, and visualize their expenses in real time. Users can add expenses, view totals, and review recent transactions through a clean, responsive interface. The app aims to make personal finance simple and accessible, reducing the stress of managing day-to-day spending.

# Key Features:

Add, delete, and view expenses dynamically

Automatic total calculations

Recent transactions overview

Fully responsive design for desktop, tablet, and mobile

# Technologies: 

HTML, CSS, JavaScript, and optional localStorage for data persistence

# Purpose: 

To provide a user-friendly, interactive way to monitor personal finances while maintaining a focused and intuitive design.
