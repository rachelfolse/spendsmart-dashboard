# SpendSmart Dashboard

## Overview
The SpendSmart Dashboard is a web application designed to help users track, manage, and visualize their expenses in real time. Users can add expenses, view totals, and review recent transactions through a clean, responsive interface. The app aims to make personal finance simple and accessible, reducing the stress of managing day-to-day spending.

## Live Site
https://rachelfolse.github.io/spendsmart-dashboard

## Purpose
The purpose of this application is to provide a user-friendly, interactive way to monitor personal finances while maintaining a focused and intuitive design. It allows users to quickly understand their spending habits and make better financial decisions.

## Key Features
- Add, delete, and view expenses dynamically  
- Automatic total calculations  
- Recent transactions overview  
- Persistent data storage using Supabase  
- Fully responsive design for desktop, tablet, and mobile  

## Technologies Used
- HTML  
- CSS  
- JavaScript  
- Supabase (database and data persistence)  

## How to Use
1. Navigate to the live site  
2. Add an expense by entering amount, description, and category  
3. View total spending on the dashboard  
4. Delete individual expenses or clear all entries  

## Future Improvements
- Add charts/visualizations for spending trends  
- User authentication for personalized accounts  
- Debit/credit options for charges
